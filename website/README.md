# clairix.app

The marketing website for Clairix. Astro, static output, deployed to Cloudflare Pages.
No analytics, no cookies, no third-party requests: every byte is served from clairix.app.

## Commands

Run from this `website/` folder. Node 22.22 or newer (see `.nvmrc`).

| Command | What it does |
|---|---|
| `npm ci` | Install exact dependencies from `package-lock.json` |
| `npm run dev` | Sync the brand files, then start the dev server at http://localhost:4321 |
| `npm run build` | Sync the brand files, then build the static site into `dist/` |
| `npm run preview` | Serve the built `dist/` locally |
| `npm run check` | Type-check the project with `astro check` |
| `npm run sync-brand` | Copy tokens, fonts, logos and icons from `../brand` (runs automatically before dev, build and check) |
| `node scripts/render-og.mjs` | Re-render the per-page Open Graph images in `public/og/` (needs Playwright; commit the PNGs) |

## Cloudflare Pages settings

| Setting | Value |
|---|---|
| Production branch | `main` |
| Framework preset | Astro |
| Root directory (advanced) | `website` |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Environment variable | `NODE_VERSION` = `22.22.0` |
| Environment variable | `ASTRO_TELEMETRY_DISABLED` = `1` |

The build reads `../brand`, so Pages must build from a full checkout of the repository
(the default). Custom domain: add `clairix.app` under the project's Custom domains; the zone
is already on Cloudflare.

`public/_headers` sets the Content-Security-Policy (self only), HSTS, `nosniff`,
`Referrer-Policy: strict-origin-when-cross-origin`, a Permissions-Policy that denies camera,
microphone and geolocation, and a one-year immutable cache for the hashed files in `/_astro/`.
`public/_redirects` holds the short links (`/play`, `/full`, `/delete`, `/disclosure`,
`/egress`) and `/pricing` to `/`.

The CSP has no `'unsafe-inline'`. Keep it that way: no inline `<script>` (other than
JSON-LD), no `style=""` attributes, no `define:vars`. Astro bundles component scripts and
styles into files under `/_astro/`.

## Where things live

| Path | Contents |
|---|---|
| `src/config/release.ts` | Clairix Full version, APK URL, SHA-256, release notes, Open Collective URL |
| `src/config/site.ts` | Navigation, footer, per-page titles, descriptions and Open Graph lines |
| `src/content/docs/*.md` | Security, Support, Press, Privacy, Terms and Delete-account copy |
| `src/content/features/*.md` | One file per feature section on /features |
| `src/pages/` | One file per page; `index.astro` holds the home page copy |
| `src/lib/icons.ts` | The Clairix icon set (24 px grid, chamfered) |
| `src/components/FeatureVisual.astro` | Feature artwork built from the brand system |
| `src/components/Screenshot.astro` | The slot for real app screenshots |
| `scripts/sync-brand.mjs` | Brand sync (tokens, fonts subset to Latin, logos, icons) |

Brand sources are never copied by hand. `src/styles/tokens.css`, `src/assets/brand/`,
`public/fonts/` and the icons in `public/` are generated by `sync-brand` and git-ignored.
Change `brand/` and rebuild.

## Releasing Clairix Full

Edit `src/config/release.ts`:

```ts
export const release = {
  version: '2.7.0',
  apkUrl: 'https://…/clairix-full-2.7.0.apk',
  sha256: '<64 hex characters of that exact file>',
  releaseNotesUrl: 'https://…',
};
```

Until both `apkUrl` (HTTPS) and a well-formed `sha256` are set, /download shows
"Coming with the first beta" instead of a download button or checksum. The Open Collective
link (`funding.openCollectiveUrl`) appears in the footer and on /support only once it is set.

## Adding app screenshots

Real screenshots only. Put the image in `src/assets/screenshots/`, then pass it to the
feature's visual:

```astro
---
import sweep from '../assets/screenshots/camera-sweep.png';
---
<FeatureVisual variant="lens" label="Lens glint" screenshot={sweep}
  screenshotAlt="Camera sweep with one lens marked in red" />
```

`<Screenshot>` renders nothing while `src` is empty, so the slot can stay in place. Astro
generates responsive WebP sizes at build time.

## The theme easter egg

The footer "Signal" control (and clicking the big mark in the home hero) switches the site
between the four brand themes: Acid, Infrared, Hazard and Volt. The choice is stored in
`localStorage` under `clx-theme` (wrapped in try/catch) and restored before first paint by
`public/theme-init.js`. The logo files are never recoloured; per the brand book they stay Acid.
